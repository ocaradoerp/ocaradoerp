# O Cara do ERP — site

Landing page estática de www.ocaradoerp.com.br, publicada pelo GitHub Pages.

- `index.html` — página completa (estilo e script dentro dela)
- `assets/img` — foto, ícone e imagem de compartilhamento
- `CNAME` — domínio do site

Para editar textos, abra `index.html` no GitHub, clique no lápis, altere e salve (commit). O site atualiza em 1 a 2 minutos.
